# Legacy & Prototype Files

This directory holds legacy prototypes and early iterations of BT-Manager components:

- **CustomTkinter Desktop App** (`main.py`): Early Python desktop GUI implementation.
- **PowerShell REST Listener** (`scripts/*.ps1`): Early PowerShell API & Mech Builder scripts.

These components have been superseded by the production architecture:
- **FastAPI Backend Service**: `apps/api/main.py`
- **Next.js Web Dashboard**: `apps/web/pages/index.js`
- **Electron Container**: `main.js`
- **Domain Agent Modules**: `packages/agents/`
